# 均分绩点模拟器

在浏览器里导入并核对成绩，管理原始分数，比较模拟后的均分和 GPA。也可以查看学期趋势、WES 估算，或通过目标反推和未来预测规划成绩。

## 使用流程

首页右侧是一座微缩 3D 庭院。点云朵切换晴天、多云和雨天，男孩会转圈、抬头看云或撑起伞。点路灯可以切换昼夜。也可以用键盘操作下方按钮。场景在浏览器本地绘制，开启减少动态效果或设备无法渲染 3D 时，会显示对应天气的静帧。下方模拟与分析区域展示六门可编辑的示例课程。首次导入后展示你的成绩，示例课程单独保存在本机。

1. 默认使用「本地解析」。Excel（`.xlsx`）和 UTF-8 CSV 直接读取表格；PDF 与 PNG、JPG、WebP 图片使用浏览器端中英文 OCR。也可以手动添加课程。配置自部署智能体后，可改选「AI 解析」发送文件。
2. 表头包含「课程名称」「学分」「成绩」。可选列为「学期」「课程类型」。成绩使用百分制，学期使用从 1 开始的序号。
3. 在预览表里编辑、删除或补录课程，再点击「确认导入并查看成绩」。导入会追加课程并跳过完全重复的条目。
4. 在「成绩管理与模拟」选择 GPA 算法、编辑模拟分数，或使用目标反推和未来预测。在「成绩分析」查看图表和 WES 估算。

确认后的成绩、设置和存档保存在当前浏览器。本地 OCR 首次使用时从同一站点加载识别引擎和字库，成绩文件留在浏览器。OCR 优先提取类似「课程名 学分 成绩」的行。表格有多列、跨行或扫描模糊时，可以查看 OCR 原文，按该格式整理后重新提取。

明确选择「AI 解析」时，原文件会发送到你配置的自部署接口。两种解析方式都先显示核对表，确认后才保存。

## 导出成绩与模拟报告

在「图表分析」顶部点击「导出 Word」或「导出 PDF」，即可下载包含成绩汇总、原始与模拟成绩明细、成绩分布、学期 GPA 趋势、课程提分贡献、多算法对比、提分潜力，以及已保存的预测与反推方案的报告。示例数据会明确标注。未应用的反推方案按保存快照导出，成绩或算法变化后需重新计算。

文件完全在浏览器本地生成，不消耗 AI 额度，也不包含密钥。Word 为真正的 `.docx` 文件，正文和表格可编辑；图表为静态图片。PDF 使用图片排版以保证离线中文显示，正文暂不支持文本搜索和复制。导出使用当前所选算法，与页面中的课程是否折叠无关。

页面底部有「免责声明与数据说明」，导出的报告也包含声明。本工具仅供规划与模拟，不是学校成绩证明或 WES 官方认证，识别及 AI 建议需要人工核实。

## AI 成绩分析与选校

首页、导入成绩、成绩模拟、图表分析、WES 模拟和 AI 分析与选校依次排列在同一页面。顶部导航滚动至对应区域，当前区域保持下划线。每张图表可以单独点击重绘，改分后会同步更新。

在 AI 页面填写兼容 OpenAI Chat Completions 的接口地址、模型名称和自己的 API Key，选择留学申请、国内升学或毕业达标方向，再填写目标并生成分析。接口支持基础地址（如 `https://api.openai.com/v1`）或完整的 `/chat/completions` 地址，需要允许浏览器跨域调用。Key 保存在页面内存中，刷新后清除。分析报告保存在当前浏览器中，选校候选需结合学校官网条件核实。

## 本地运行

使用 Node.js 24，在项目目录执行：

```sh
npm ci
npm run build
npm run preview
```

打开 [本地预览](http://localhost:3000/)。

预览地址由 `npm run preview` 在本机提供，需要保持命令运行。如果关闭了终端，重新运行该命令即可。

## 接入自部署智能体

网页提供直接配置入口：「导入成绩 → AI 解析」，填写解析接口与访问令牌，点击「测试连接」。接口地址可选择记住，令牌只保留在本次页面内存中，刷新后清除。测试连接只检查服务是否启动及必要配置是否存在，不验证模型 Key 或消耗模型额度。

没有服务时，展开「还没有智能体？部署与接口说明」下载自部署包。包内包含 Python 服务、Dockerfile、Compose 和环境变量模板。也可以直接使用仓库中的 [agent/README.md](agent/README.md)。模型 API Key 配置在服务端，网页只填访问令牌。费用由服务端配置的模型账户承担。

仍可在构建网页时设置 `GPA_AGENT_URL` 作为默认接口地址。使用 GitHub Pages 时，在仓库 **Settings → Secrets and variables → Actions → Variables** 添加同名仓库变量，然后重新运行部署。

页面会向该地址发起 `POST` 请求，使用 `multipart/form-data` 的 `file` 字段上传原文件。接口应同步返回 HTTP 200 和以下结构：

```json
{
  "records": [
    { "courseName": "高等数学", "credits": 4, "score": 88, "semester": 1, "category": "专业必修" }
  ]
}
```

使用百分制成绩和从 1 开始的学期序号。智能体无法识别的字段可以返回 `null`，网页会在核对表中标记待填写的行。部署接口需使用 HTTPS，并允许网页地址跨域访问。调试时可用本机 HTTP 接口。若智能体需要服务密钥，用自部署接口在服务端调用智能体，并将密钥保存在服务端环境变量中。接口地址会出现在公开网页的构建产物中。

## 发布网站

推荐使用 Cloudflare 静态托管，或在香港、新加坡服务器上托管 `site-dist/`。详细步骤见 [部署指南](docs/DEPLOYMENT.md)。

Cloudflare Workers 连接本仓库时，构建命令为 `npm run build`，部署命令为 `npx wrangler deploy`，使用仓库中的 `wrangler.jsonc`。Cloudflare Pages 则选择框架 None、构建命令 `npm run build`、输出目录 `site-dist`。

GitHub Actions 只做构建检查并保存网站产物，不自动发布到 GitHub Pages。源代码公开与网站托管是独立的步骤，仓库上传完成不代表网站已经上线。

本仓库仅分发浏览器版本及可选解析智能体；旧平台专用技能、个人成绩、工作区记录及密钥不包含在发布源码中。MIT 许可证沿用仓库已有文件，第三方依赖仍受其各自许可证约束。
